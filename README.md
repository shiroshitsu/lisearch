## エレベーターピッチ

事前にスライド共有がない、研究を詳しく説明するゼミで留学生の英語発表を発表中に理解したい日本人学生（学部4年生・修士1年生）向けの、「ヨウヤクゼミ」というプロダクトは、ゼミ発表の要約が、項目（背景・目的・手法…）ごとに見れるWebアプリです。
これは、発表の流れに合わせて、難しい言葉を易しく言い換えた要約を見ることができ、文字起こし、録画をAIや要約アプリに渡すのとは違って、研究の流れに合わせて項目を埋めていく機能、発表中の要約機能が備わっている。
